# Deep-Tech Investment Notebook

A static investment research microsite covering Octobotics and PierSight.

## Structure

- `index.html` - guided question experience, company deep dives and common thesis
- `octobotics.html` - Octobotics investment deep dive
- `piersight.html` - PierSight investment deep dive
- `questions.js` - 25 approved fixed questions and responses
- `app.js` - guided question search, browse dropdown and company filters
- `styles.css` - shared responsive visual system

The homepage does not allow free-form questions. Reviewers must choose one of the approved questions from the dropdown.
